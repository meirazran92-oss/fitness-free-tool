# מחשבון קלוריות + בניית תוכנית אימונים אישית

עמוד לידים של **מאיר עזרן - מאמן כושר אונליין** (`index.html`), בעיצוב
מינימליסטי בצבעי המותג (כחול-נייבי / שחור / חום). אוסף מין, גיל, גובה,
משקל, רמת פעילות, מטרה, **אזורי התמקדות** (בטן/ישבן ורגליים/זרועות/גב/
כתפיים/חזה - ניתן לבחור כמה), רמת ניסיון, ימי אימון וציוד זמין, ומחשב:

- קלוריות יומיות מומלצות + פירוט חלבון/פחמימה/שומן (נוסחת Mifflin-St Jeor).
- תוכנית אימונים שבועית מלאה, מותאמת למין, לרמת הניסיון, למספר ימי האימון
  ולציוד (חדר כושר / משקולות בבית / משקל גוף בלבד).
- **תוספת ממוקדת** - 1-2 תרגילים נוספים לכל אזור התמקדות שנבחר, כדי
  שהתוכנית תרגיש בנויה סביב המטרה הספציפית של המשתמש ולא גנרית.

העמוד הראשון כולל תמונת רקע של מאיר (בעיבוד גרפי דואטון כחול/שחור - לא
תמונה "נקייה" אלא רקע אווירתי), ובתחתית כל עמוד מופיעה חתימת "מאיר עזרן ·
מאמן כושר אונליין".

בסוף התהליך (לפני הצגת התוצאה) נאספים שם וטלפון, ונשלחים ברקע לגיליון
לידים ב-Google Sheets דרך Apps Script Web App - כלי הלידים המלא (כולל
אוטומציית הוואטסאפ שמזינים אליה) מנוהל בריפו נפרד ופרטי; **הריפו הזה מכיל
רק את הדף הציבורי עצמו**, כדי לא לחשוף שום דבר מהמערכת העסקית.

## מבנה הקבצים

- `index.html` - הדף עצמו (HTML+CSS+JS, קובץ יחיד, בלי תלות בשרת).
- `assets/coach-hero.jpg` - תמונת הרקע לעמוד הראשון.
- `.github/workflows/deploy-pages.yml` - פריסה אוטומטית ל-GitHub Pages.

## הגדרה - לפני שמפרסמים

פתחו את `index.html`, חפשו `CONFIG` בתוך תג ה-`<script>`:

```js
var CONFIG = {
  ENDPOINT_URL: '',   // כתובת ה-Web App מ-Apps Script (מסתיימת ב-/exec)
  SHARED_SECRET: '',  // אותו ערך כמו LEAD_FORM_SECRET ב-Script Properties
  COACH_NAME: 'מאיר',
};
```

עד שממלאים את `ENDPOINT_URL`, הדף עובד מקומית לגמרי (מחשב ומציג תוצאות)
אבל לא שולח שום ליד לשום מקום.

## פרסום - GitHub Pages (אוטומטי)

יש workflow מוכן (`.github/workflows/deploy-pages.yml`) שמפרסם את `index.html`
ל-GitHub Pages בכל פוש ל-`main`. נדרשת הפעלה חד-פעמית (רק בעל הריפו יכול):

**Settings ← Pages ← Build and deployment ← Source: "GitHub Actions"**

אחרי זה הכתובת הציבורית תופיע תחת Settings ← Pages, בפורמט:
`https://meirazran92-oss.github.io/fitness-free-tool/`

## בדיקה

1. פתחו את הקישור, מלאו את הטופס מקצה לקצה.
2. ודאו שבגיליון הלידים נוספה שורה עם השם/טלפון שהזנתם.
3. ודאו ש-`CONFIG.DRY_RUN` בפרויקט Apps Script הראשי מכובה (`false`) רק אחרי
   שבדקתם שהכל תקין - כדי שהודעות וואטסאפ אמיתיות לא ייצאו בטעות באמצע בדיקה.
